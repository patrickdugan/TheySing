# Native They Sing scenario projection

Use alongside `hypergames/triad_fog/SKILL.md` and GPTStoryworld's `codex-skills/hyperworld-builder/SKILL.md`. Preserve the original TS-HG-01 frozen source and results: the new TS-HG-02 projection is a separate interface layer.

## Inputs

- A public *They Sing* hypergame state generated by `TriadGame.new(seed)`.
- The explicit subset returned by `visible(actor)['public_world']`.
- A seed and the canonical role map Meridian → HEGEMON, Helios → STATE, Undersong → INFILTRATOR.

The native TypeScript `ScenarioOverlay` is a shared starting state. Its contents may be shown to **all** agents. A field belongs in this overlay only when it is public to all parties. Never put individual players' `own_traits`, private RSI depths, Bitcoin reserves or liabilities, unsealed p/p2 forecasts, hidden evaluation shifts, or sealed grades here.

## Workflow

From repository root:

```bash
python hypergames/triad_fog/export_native_overlay.py \
  --seed 2026111801 \
  --out playtest/scenarios/three-voices-fog.json \
  --harness-config playtest/sample-triad-fog-tournament.json --check

python -m unittest discover -s hypergames/triad_fog/tests -p 'test_*.py' -q
npm run build:harness
```

The Python runtime remains authoritative for dynamical beliefs, population consent, provenance, resource budgets, RSI, and evaluation gates. A native harness run demonstrates scenario compatibility, not mathematical or behavioral parity between the two engines.
